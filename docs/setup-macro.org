* The ~setup~ macro

Helheim configures packages with heavily modified [[https://elpa.gnu.org/packages/setup.html][setup]] macro: most default
keywords are removed and replace with custom ones.

"Explicit is better than implicit." Unlike ~use-package~, the ~setup~ macro is
not declarative — it does not rearrange code blocks.

It is just syntactic sugar[fn:1]. In the most basic case
#+begin_src emacs-lisp
(setup FEATURE
  body ...)
#+end_src
is the same as
#+begin_src emacs-lisp
(progn
  body ...)
#+end_src

It was created, out of tiredness finding out that something doesn't work
because of obscure ~use-package~ macro expansion. Internally, it
calls ~macroexpand-all~ with a custom ENVIRONMENT, allowing macros to be
defined only within the scope of the ~setup~ form.

#+begin_src emacs-lisp
(setup FEATURE
  (:keyword arg ...)
  body ...)
#+end_src

To see how a form expands, place the cursor after its closing paren and press =,ep=.

** Quick reference

| Keyword        | Purpose                                            |
|----------------+----------------------------------------------------|
| ~:install~       | Install via the active package manager             |
| ~:setopt~        | Set a variable only if the user has not changed it |
| ~:require~       | ~(require 'FEATURE)~                                 |
| ~:when~          | Guard the entire form on a condition               |
| ~:after~         | Wrap body in ~with-eval-after-load~ for a feature    |
| ~:after-load~    | Same, but for the /current/ feature                  |
| ~:blackout~      | Hide a minor mode from the mode line               |
| ~:command~       | Declare an ~autoload~ for a command                  |
| ~:after-init~    | Run body in ~after-init-hook~                        |
| ~:defer~         | Evaluate body when Emacs is idle after startup     |
| ~:hook~          | ~add-hook~; accepts many-to-many mapping             |
| ~:with-keymap~   | Change the keymap body binds into                  |
| ~:with-keymaps~  | Repeat body for a list of keymaps                  |
| ~:bind~          | Bind keys in the current keymap                    |
| ~:unbind~        | Remove bindings from the current keymap            |
| ~:global-bind~   | Bind keys globally                                 |
| ~:global-unbind~ | Remove global bindings                             |
| ~:mode~          | Add an entry to ~auto-mode-alist~                    |

** Package installation
*** ~:install~

#+begin_src emacs-lisp
(:install PACKAGE &rest RECIPE)
(:install t)   ; install the feature itself
(:install nil) ; do not install (same as :built-in)
#+end_src

Dispatches to the package manager configured in ~helheim-package-manager~
(~'elpaca~ or ~'straight~). When ~PACKAGE~ is ~t~, the feature name is used as the
package name.

#+begin_src emacs-lisp
(setup orderless
  (:install t)) ; install `orderless'

(setup hel-leader
  (:install hel-leader :host github :repo "anuvyklack/hel-leader"))
#+end_src

*** ~:elpaca~ / ~:straight~

#+begin_src emacs-lisp
(:elpaca PACKAGE &rest RECIPE)
(:straight PACKAGE &rest RECIPE)
#+end_src

Manager-specific install keywords. Prefer ~:install~ for portability; use
these only when a recipe is meaningfully different between managers or when
targeting a specific manager is intentional.

** ~:setopt~ — Variable defaults

#+begin_src emacs-lisp
(:setopt VARIABLE VALUE
         VARIABLE VALUE ...)
#+end_src

Sets ~VARIABLE~ to ~VALUE~ only if the user has not already changed it from its
original default. This is Helheim's mechanism for supplying sensible
defaults without clobbering user settings — even when Elpaca runs package
config closures asynchronously, after ~init.el~ has already run.

#+begin_src emacs-lisp
(setup corfu
  (:install t)
  (:setopt corfu-auto t
           corfu-auto-delay 0.24
           corfu-cycle t))
#+end_src

Do /not/ use ~:setopt~ in your own ~init.el~; use plain ~setopt~ there. ~:setopt~ is
for Helheim module defaults.

** Loading and timing
*** ~:require~

#+begin_src emacs-lisp
(:require FEATURE)
(:require t) ; require the current feature
#+end_src

Emits ~(require 'FEATURE)~. Use ~t~ to require the feature named in the ~setup~ call.

#+begin_src emacs-lisp
(setup hel-leader
  (:install hel-leader :host github :repo "anuvyklack/hel-leader")
  (:require t))
#+end_src

*** ~:after~

#+begin_src emacs-lisp
(:after FEATURE)
(:after FEATURE1 FEATURE2)
#+end_src

Defers the entire ~setup~ body until another ~FEATURE~ (or all list of features) have
been loaded.

#+begin_src emacs-lisp
(setup vertico-directory
  (:after vertico)
  (:require t)
  (:hook rfn-eshadow-update-overlay-hook vertico-directory-tidy))

(setup nerd-icons-completion
  (:install t)
  (:after marginalia)
  (nerd-icons-completion-mode))
#+end_src

Note: ~:after~ applies to the whole ~setup~ form. Use ~:after-load~
when only /part/ of the form should be deferred.

*** ~:after-load~

#+begin_src emacs-lisp
(:after-load
  BODY ...)
#+end_src

Wraps ~BODY~ in ~(with-eval-after-load 'CURRENT-FEATURE ...)~. Use this when you
need some code (like a global mode call) to run immediately while deferring
other code (like keymap bindings) until the package is actually loaded.

#+begin_src emacs-lisp
(setup corfu
  (global-corfu-mode) ; runs immediately
  (:after-load
    (:with-keymap corfu-map
      (:bind "<tab>" 'corfu-next
             "RET"   'corfu-insert))))
#+end_src

expands to

#+begin_src emacs-lisp
(progn
  (global-corfu-mode)
  (eval-after-load 'corfu
    #'(lambda ()
        (hel-keymap-set corfu-map
          "<tab>" 'corfu-next
          "RET" 'corfu-insert))))
#+end_src

*** ~:defer~

#+begin_src emacs-lisp
(:defer
  BODY ...)
#+end_src

Schedules ~BODY~ to run when Emacs has been idle for
~helheim-initial-deferred-task-timeout~ seconds after startup
(default: 2s). Subsequent deferred tasks each wait an additional
~helheim-deferred-task-timeout~ seconds (default: 0.75s).

Use this for optional setup that should not slow down Emacs startup.

#+begin_src emacs-lisp
(setup some-package
  (:install t)
  (:defer
    (some-package-mode 1)))
#+end_src

expands to:

#+begin_src emacs-lisp
(elpaca 'some-package
  (helheim-defer #'(lambda ()
                     (some-package-mode 1))))
#+end_src

*** ~:after-init~

#+begin_src emacs-lisp
(:after-init symbol)
(:after-init BODY ...)
(:after-init (lambda () …))
#+end_src

Adds ~BODY~ to ~after-init-hook~ (or ~elpaca-after-init-hook~ when Elpaca is the
active package manager). ~BODY~ can be a function symbol, a lambda, or arbitrary
forms that will wrapped in a lambda.

#+begin_src emacs-lisp
(setup vertico
  (:install t)
  (:after-init vertico-mode)
  (:after-init BODY ...))
#+end_src

expands to

#+begin_src emacs-lisp
(elpaca 'vertico
  (add-hook 'elpaca-after-init-hook #'vertico-mode)
  (add-hook 'elpaca-after-init-hook #'(lambda () body ...)))
#+end_src
 
** ~:hook~

#+begin_src emacs-lisp
(:hook HOOK FUNCTION)
(:hook HOOK (FUNCTION1 FUNCTION2 ...))
(:hook (HOOK1 HOOK2 ...) FUNCTION)
(:hook HOOK (lambda () ...))
(:hook HOOK) ; expands to (add-hook 'HOOK 'FEATURE-mode)
#+end_src

Adds functions to hooks. Accepts many-to-many mappings: if either argument
is a list, all combinations are registered.

#+begin_src emacs-lisp
(setup corfu-history
  (:hook global-corfu-mode-hook corfu-history-mode))

(setup cape
  (:install t)
  (:hook completion-at-point-functions (cape-dabbrev cape-file
                                        cape-elisp-block cape-history)))

(setup hel-paredit
  (:hook (emacs-lisp-mode-hook lisp-data-mode-hook) hel-paredit-mode))

(setup prog-mode
  (:hook prog-mode-hook (lambda () (setq-local line-move-visual nil))))
#+end_src

** Key bindings

Helheim key-binding keywords call ~hel-keymap-set~ and ~hel-keymap-global-set~
(from [[https://github.com/anuvyklack/hel][Hel]]) instead of the standard ~keymap-set~. This means they accept an
optional ~:state~ argument that scopes bindings to a specific Hel modal state.

*** ~:with-keymap~ / ~:with-keymaps~

#+begin_src emacs-lisp
(:with-keymap KEYMAP
  BODY ...)

(:with-keymaps (KEYMAP1 KEYMAP2 ...)
  BODY ...)
#+end_src

Changes the keymap that inner ~:bind~ / ~:unbind~ calls target.
~KEYMAP~ can be any form that evaluates to a keymap.
~:with-keymaps~ repeats ~BODY~ for every keymap in the list.

#+begin_src emacs-lisp
(setup corfu
  (:after-load
    (:with-keymap corfu-map
      (:bind
        "<tab>" 'corfu-next
        "RET"   'corfu-insert
        "C-h"   'corfu-info-documentation))))
#+end_src

*** ~:bind~

#+begin_src emacs-lisp
(:bind [:state STATE] KEY DEFINITION ...)
#+end_src

Binds ~KEY~ → ~DEFINITION~ pairs in the /current/ keymap (the feature's own map, or
the one set by ~:with-keymap~). ~KEY~ and ~DEFINITION~ follow ~keymap-set~ conventions.
~:state~ (optional) restricts the binding to a Hel modal state or a list of states.

#+begin_src emacs-lisp
(:with-keymap agent-shell-mode-map
  (:bind :state 'normal
    "z '" 'agent-shell-prompt-compose)
  (:bind
    "C-c RET" 'dired-jump))
#+end_src

*** ~:unbind~

#+begin_src emacs-lisp
(:unbind [:state STATE] KEY ...)
#+end_src

Removes ~KEY~ bindings from the current keymap.

*** ~:global-bind~

#+begin_src emacs-lisp
(:global-bind [:state STATE] KEY DEFINITION ...)
#+end_src

Binds ~KEY~ → ~DEFINITION~ in the global keymap. Accepts the same
optional ~:state~ as ~:bind~.

#+begin_src emacs-lisp
(setup helheim
  (:global-bind :state 'normal
    "z SPC" 'cycle-spacing
    "z ."   'set-fill-prefix)
  (:global-bind :state 'insert
    "C-/"   'hippie-expand)
  (:global-bind
    [remap keyboard-quit] 'helheim-keyboard-quit
    "C-x C-b"             'ibuffer-jump))
#+end_src

*** ~:global-unbind~

#+begin_src emacs-lisp
(:global-unbind [:state STATE] KEY ...)
#+end_src

Removes ~KEY~ bindings from the global keymap.

** ~:blackout~ — Mode line

#+begin_src emacs-lisp
(:blackout t)                          ; hide current feature's mode
(:blackout MODE-SYMBOL)                ; hide a named mode
(:blackout " Lighter")                 ; replace lighter for current mode
(:blackout (MODE-SYMBOL . " Lighter")) ; named mode with replacement
#+end_src

Hides a minor mode from the mode line using the [[https://github.com/raxod502/blackout][blackout]] package.
Multiple ~:blackout~ arguments may be combined in one call.

#+begin_src emacs-lisp
(setup org-indent
  (:blackout t))

(setup outline
  (:blackout outline-mode
             outline-minor-mode))
#+end_src

** Autoloads and file associations
*** ~:command~

#+begin_src emacs-lisp
(:command COMMAND ...)
#+end_src

Generates an ~autoload~ declaration for each ~COMMAND~, so the
function is available interactively before the package loads.

#+begin_src emacs-lisp
(setup org-cliplink
  (:install t)
  (:command org-cliplink-retrieve-title-synchronously
            org-cliplink-org-mode-link-transformer))
#+end_src

*** ~:mode~

#+begin_src emacs-lisp
(:mode (REGEXP . MODE))
#+end_src

Adds the cons cell to ~auto-mode-alist~. Repeatable.

#+begin_src emacs-lisp
(setup json-mode
  (:mode ("\\.js\\(?:on\\|[hl]int\\(?:rc\\)?\\)\\'" . json-mode)))

(setup markdown-mode
  (:mode ("README\\.md\\'" . gfm-mode)))
#+end_src

** ~:when~ — Conditional evaluation

#+begin_src emacs-lisp
(:when CONDITION)
#+end_src

Guards the entire ~setup~ body: no code runs unless ~CONDITION~ evaluates to non-nil
at load time. Place ~:when~ before other keywords so the guard is obvious.

#+begin_src emacs-lisp
(setup bash-ts-mode
  (:when (treesit-available-p))
  (add-to-list 'major-mode-remap-alist '(sh-mode . bash-ts-mode)))
#+end_src

* Footnotes

[fn:1] The exeptions are ~:when~, ~:after~ and ~:elpaca~ which are enclose the
whole ~setup~ form in their constructions.
