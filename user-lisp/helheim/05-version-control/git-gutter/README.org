* helheim-diff-hl

Install and configure [[https://github.com/dgutov/diff-hl][diff-hl]] package which shows git-diffs indicators in the
margin.

** Enabel
#+begin_src emacs-lisp
(require 'helheim-diff-hl)
#+end_src

** Usage

Related keys are under =SPC v= prefix in ~diff-hl-command-map~ keymap.

| ~[v~ / ~]v~ | Show prev / next hunk |


| ~SPC v [~ / ~SPC v ]~ | Goto prev / next hunk |
| ~SPC v {~ / ~SPC v }~ | Show prev / next hunk |


| ~SPC v V~ | View diff hunk at point   |
| ~SPC v s~ | Stage diff hunk at point  |
| ~SPC v r~ | Revert diff hunk at point |
| ~SPC v =~ | Goto diff hunk            |
