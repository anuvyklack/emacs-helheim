* helheim-org-node

Install and configure [[https://github.com/meedstrom/org-node][Org-node]] — a more perfomant [[https://www.orgroam.com/][Org-roam]] alternative.

** Enable
#+begin_src emacs-lisp
(require 'helheim-org-node)
#+end_src

** Hacks

- Nodes with an =:IGNORE:= or =:ROAM_EXCLUDE:= property are ignored by org-node
  commands.

- New files use the [[https://protesilaos.com/emacs/denote][Denote]] naming convention:
  #+begin_example
  20250322T131856--my-node-title.org
  #+end_example

** Usage
*** Keys available everywhere

| =SPC n n= | Open or create a node                     |
| =SPC n b= | Backlinks buffer for current node         |
| =SPC n r= | Open random node                          |
| =SPC n /= | Search across all files known to org-node |

**** Maintenance

| =SPC n x x= | Reset org-mem cache                      |
| =SPC n x t= | List nodes with duplicate titles         |
| =SPC n x d= | List dead (broken) ID links              |
| =SPC n x p= | List ~org-mem~ problems                    |
| =SPC n x l= | Run ~org-lint~ on all known Org files      |
| =SPC n x f= | List all node files                      |
| =SPC n x r= | List reflinks                            |
| =SPC n x a= | Rename asset file and update links to it |

*** Keys in Org-mode buffers
**** Notes (=C-c n=)

| =C-c n b= | Backlinks buffer for node at point                      |
| =C-c n i= | Add ID — make a node                                   |
| =C-c n I= | Add ID and =ROAM_EXCLUDE= properties — don't make a node |
| =C-c n l= | Insert link to another node                             |
| =C-c n w= | ~org-node-refile~                                         |

**** Insert (=, i=)

| =, i i= | Add ID to heading — make it a node  |
| =, i I= | Add ID and set =ROAM_EXCLUDE= property |
| =, i n= | Insert link to another node          |
| =, i a= | Add alias to current node            |
| =, i q= | Add tags to current node             |

**** Links (=, l=)

| =, l n= | insert link to node                |
| =, l t= | insert node translusion            |
| =, l y= | insert node translusion as subtree |

** Customization

- ~helheim-org-node-visit-backlink-in-another-window~ ::
  When set, pressing =Enter= in the backlinks buffer opens the target node in
  another window instead of the current one. Default: =nil=.
