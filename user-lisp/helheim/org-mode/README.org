Modules in this directory provide one of the best outliners and personal
knowledge management systems available, powered by Org-mode and Hel.

- *Offline-first* — all your data belongs only to you.
- *Unmatched editing* capabilities of any outliner available today — none of
  the existing note-taking apps provide fully capable Vim emulation, not to
  mention Kakoune or Helix.
- *Org-mode advantages:*
  - Rich markup — more powerful than Markdown, with LaTeX as a first-class
    citizen (like HTML for Markdown).
  - Task management.
  - The best code snippet support of any outliner.
  - Tables.
- *Bidirectional links* for seamless navigation.
- *Daily notes* — your main scratchpad and a better "Inbox".
