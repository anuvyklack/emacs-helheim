* helheim-eglot

This module configures the Eglot LSP client and the Flymake diagnostics
framework, both built into Emacs.

** Enable
Add following line to your init.el file:
#+begin_src emacs-lisp
(require 'helheim-eglot)
#+end_src

** Customization

If you want Flymake diagnostics to be shown only in sideline:
#+begin_src emacs-lisp
(use-package helheim-eglot
  :config
  (add-hook 'sideline-mode-hook (lambda ()
                                  (remove-hook 'eldoc-documentation-functions
                                               'flymake-eldoc-function t))))
#+end_src

** Keybindings

| =K= or =M= | Show on hover documentation |
| =gd=     | Goto definition             |
| =gD=     | Goto declaration            |
| =gr=     | Find references             |
| =gt=     | Goto type definition        |
| =gi=     | Find all implementations    |

-----

*** =SPC l= (or =C-c l=) is a prefix for LSP commands

| =SPC l RET= | Start (or restart) LSP session in current buffer |
| =SPC l Q=   | Shutdown LSP session                             |

-----

| =SPC l r= | Rename symbol                                                  |
| =SPC l f= | Format region or buffer                                        |
| =SPC l t= | Type hierarchy                                                 |
| =SPC l c= | Call hierarchy                                                 |
| =SPC l a= | Code actions                                                   |
| =SPC l o= | Organize imports (~source.organizeImports~ code action)          |
| =SPC l q= | Quickfix (~quickfix~ code action)                                |
| =SPC l e= | Extract into separate function (~refactor.extract~ code actions) |
| =SPC l i= | Inline function (~refactor.inline~ code action)                  |
| =SPC l R= | Refactor (~refactor.rewrite~ code action)                        |

-----

*** =SPC t= (or =C-c t=) is general Helheim prefix for various toggleable features

| =SPC t h= | Toggle inlay hints                 |
| =SPC t s= | Toggle semantic tokens highlihting |

** Warning

DO NOT try to update Eglot with ~eglot-upgrade-eglot~ function. It will try to do
it via =package.el= package manager, but Helheim disables it since uses Elpaca.
