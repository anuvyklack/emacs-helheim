* helheim-tab-bar

Configure *tab-bar* mode — each tab represents a set of windows (like in Vim).

** Enable
#+begin_src emacs-lisp
(require 'helheim-tab-bar)
#+end_src

** Usage

- =C-w tab= ::
  Create a new tab. With =M-u= (~universal-argument~), detach the current window
  into a new tab.

- =C-tab= / =C-S-tab= or =]t= / =[t= :: *next* / *previous* tab

- =C-w t= :: Prefix for tab-bar keys

  | =C-w t n=       | Display the buffer of the next command in a new tab |
  | =C-w t c=       | Close tab                                           |
  | =C-w t g=       | Add current tab to group                            |
  | =C-w t u=       | Reopen last closed tab                              |
  | =C-w t o=       | Close all other tabs                                |
  | =C-w t w=       | Move current window to a new tab                    |
  | =C-w t r=       | Rename current tab                                  |
  | =C-w t= + =<= / =>= | Move tab to the *left* / *right*                        |
