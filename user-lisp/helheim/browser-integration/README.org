* Helheim-Browser integration

This module installs and configures [[https://github.com/KarimAziev/chrome-emacs?tab=readme-ov-file#browser-extension][chrome-emacs]] package, which provides
bi-directional content, cursor position and scroll synchronization between
online text editors and Emacs.

You also need to install the browser extension:
- [[https://chromewebstore.google.com/detail/chrome-emacs/dabdpcafiblbndpoadckibiaojbdnpjg][Chrome]]
- [[https://addons.mozilla.org/en-US/firefox/addon/chrome-emacs/][Firefox]] 

** Enable
#+begin_src emacs-lisp
(require 'helheim-browser)
#+end_src

** Usage

- =SPC SPC= or =C-c C-c= or =ZZ= — finish
- =SPC t s= — Toggle selection synchronization
