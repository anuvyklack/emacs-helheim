* helheim-deadgrep

[[https://github.com/Wilfred/deadgrep][Deadgrep]] is a nice interface for [[https://github.com/BurntSushi/ripgrep][Ripgrep]] in Emacs.

** Enable
#+begin_src emacs-lisp
(require 'helheim-deadgrep)
#+end_src

** Usage

| =SPC s s= | start a ripgrep search |

** Configuration
*** Automatically show preveiw in other window

If you want a preview in other window follows your moves in deadgrep buffer:
#+begin_src emacs-lisp
(add-hook 'deadgrep-mode-hook #'next-error-follow-minor-mode)
#+end_src
