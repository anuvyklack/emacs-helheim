** Keybindings

Also see documentation of [[https://github.com/anuvyklack/hel-paredit][hel-paredit]] which provides structural editing for
S-expressions.

| =K= or =M=  | Show documentation for symbol at cursor                        |
| =, e e=   | Evaluate sexp before cursor                                    |
| =, e f=   | ~eval-defun~ — Evaluate top-level form around cursor            |
| =, e r=   | Evaluate the selection. With no selection eval full buffer     |
| =, e b=   | Evaluate the current buffer                                    |
| =, e B=   | Byte compile the current buffer                                |
| =, e m=   | Macroexpand the form after point                               |
| =, e RET= | Evaluate sexp before point and print value into current buffer |
