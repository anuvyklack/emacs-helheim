* helheim-ghostel

Install and cofigure [[https://github.com/dakra/ghostel][Ghostel]] — a [[https://github.com/ghostty-org/ghostty][libghostty]]-powered terminal emulator.

** Enable
#+begin_src emacs-lisp
(require 'helheim-ghostel)
#+end_src

** Usage

- =SPC o t= ::
  - Start a new terminal or switch to an existing one.
  - With =M-u=, always create a new terminal.

See [[https://github.com/anuvyklack/hel-ghostel][hel-ghostel]] documentation for how Ghostel in integrated with Hel.
